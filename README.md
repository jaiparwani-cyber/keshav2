# Task 1 Rebuild - Nunjucks + Vite

This project recreates the Task 1 IISc Smart Mess website using the required strict technology stack.

## Chosen Stack

- Templating engine: Nunjucks
- Bundler/task runner: Vite

## Folder Structure

```text
src/
  templates/
    layout.njk
    pages/
    partials/
  assets/
    css/
    js/
dist/
```

## Install Dependencies

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Vite will serve the rendered pages locally.

## Build

```bash
npm run build
```

The final compiled HTML output is generated in `dist/`.
